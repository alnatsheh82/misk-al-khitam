# مِسك الختام

**أنشطة تفاعلية للتهيئة والغلق البنائي والختامي** — أداة مجانية تعمل بلا إنترنت، يصنع بها المعلم أنشطة صفية ويعرضها على السبورة الذكية أو جهاز العرض.

## التشغيل
1. نزّل المجلد كاملًا.
2. افتح الملف `ابدأ.html` في Chrome أو Edge.
3. (مستحسن) من «الإعدادات» اختر مجلد «أنشطتي» ليُحفظ فيه عملك، وخذ نسخة احتياطية دوريًا.

لا يحتاج تثبيتًا ولا خادمًا ولا اتصالًا بالإنترنت.

## ما فيه
- 27 قالبًا في ست مجموعات: أنشطة حصص المراجعة، وأسئلة واختبارات، ومطابقة وترتيب وتصنيف، ونصوص وكلمات، وعرض ونقاش، وألعاب حركية.
- الشعب والطلاب بمستويات مخفية، وعجلة «من يجيب؟»، والفرق، وأزرار التعزيز، وسجل المشاركة ولوحة الشرف.
- الجولات: عدة أنشطة في عرض واحد.
- الاستيراد من Word وPowerPoint وأوراق «معد أوراق العمل» وWordwall (بالنسخ واللصق)، والتصدير لصف أو فصل أو درس أو هدف أو نشاط.
- النسخ الاحتياطي والاستعادة، وصفحة «فحص الأداة».
- الآيات بالرسم العثماني، والرموز الإسلامية الخطية، ورموز الرياضيات والعلوم.

## بنية الملفات
| الملف | وظيفته |
|---|---|
| `app/core.js` | الأدوات الأساسية والإعدادات والأصوات والأيقونات |
| `app/storage.js` | الحفظ في المجلد أو المتصفح |
| `app/templates.js` / `templates2.js` / `templates3.js` | القوالب الأساسية |
| `app/arcade.js` | الألعاب الحركية ورسوماتها |
| `app/board.js` | لوحة التحديات |
| `app/import.js` / `wordwall.js` | الاستيراد من Word وWordwall |
| `app/rounds-import.js` | الجولات، وأوراق المعد، وحزم التصدير، وانسخه وعدّل |
| `app/backup.js` | النسخ الاحتياطي، وفحص بنية الأنشطة، وتحصين قراءة الملفات، وفحص الأداة |
| `app/classes.js` | الشعب والطلاب والعجلة وسجل المشاركة |
| `app/helpers.js` | اللغة، والنص الغني، والرموز، والآيات، وملفي، والصور المصغّرة |
| `app/feedback.js` | الإعدادات المسبقة وعبارات التهنئة |
| `app/main.js` | الواجهة والمحرّر وشاشة العرض |
| `app/shared/` | خطوط المصحف والرموز، ونص المصحف |

## مصدر النص القرآني
النص القرآني وخطه من مجمع الملك فهد لطباعة المصحف الشريف (الإصدار 22)، برواية حفص عن عاصم وبالرسم العثماني، ويُستخدم ويوزَّع مجانًا دون تعديل ولا يُباع.
